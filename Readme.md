\# PicsOS: Retro Web Photo Editor



\## Overview

PicsOS is a frontend web application that provides a fully functional, browser-based photo editing experience. Inspired by retro operating systems (Windows 95, Y2K, and Frutiger Aero aesthetics), it allows users to upload, manipulate, and export images entirely locally. The project focuses on utilizing the HTML5 Canvas API for live image processing without relying on a backend server.



\## Technologies Used

\* \*\*HTML5:\*\* Semantic structure and Canvas element integration.

\* \*\*CSS3:\*\* Custom theming engine utilizing CSS variables for dynamic aesthetic switching.

\* \*\*Vanilla JavaScript (ES6):\*\* DOM manipulation, event handling, and image processing logic.

\* \*\*Vercel:\*\* Cloud platform used for deployment and hosting.



\## Technical Highlights

\* \*\*Canvas API Integration:\*\* Handles real-time image rendering, pixel manipulation for custom filters, and overlaying stickers and frames directly within the browser context.

\* \*\*Dynamic UI Theming:\*\* Engineered a flexible CSS architecture that allows users to seamlessly switch between multiple retro visual themes on the fly.

\* \*\*Client-Side Processing:\*\* Ensures 100% user privacy and zero server latency by executing all photo editing computations locally on the user's machine.

\* \*\*Responsive Interactions:\*\* Implemented custom event listeners for drag-and-drop mechanics and live canvas updates.
